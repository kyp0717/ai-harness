# Shared sessions

Team Named Threads in the left rail: choose which shared threads to show, create a shared session, open or start its sessions.

## Sub-features

- named-list: shared shared sessions visible in the left rail
- named-visibility: choose which shared sessions to show
- create-named: create a new shared session for the team
- start-session: open or start a session from a shared session

## How to get to it (user POV)

Shared sessions appear in a left-rail section when the team has any. Create from the section header.

## Driving it with control-atlas

Requires a team account with named-thread entitlement. Skip with reason otherwise.

Create a disposable shared session, open it, delete/archive in cleanup.

## Gotchas

- Visibility toggles are per-user; do not assert team-wide absence after hiding locally.
