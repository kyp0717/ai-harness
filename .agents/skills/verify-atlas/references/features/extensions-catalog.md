# Extensions catalog

Extensions catalog / Customize sidebar panel: browse and install plugins, skills, MCPs, subagents, rules, commands, hooks; manage what is installed.

## Sub-features

- browse-catalog: search and browse installable items
- install-uninstall: install and remove a plugin or skill
- manage-installed: list and configure installed items
- mcp-connect: connect an MCP server from the panel

## How to get to it (user POV)

Open Extensions catalog from the left rail Customize entry or Preferences. Search, open a detail page, install.

## Driving it with control-atlas

Prefer a disposable sample plugin the suite can install and remove. Avoid paid/extensions catalog-account side effects.

Assert installed state in the Manage list after install, and absence after uninstall.

## Gotchas

- Some installs require confirmation trays. Complete or dismiss them deliberately.
- Team-required plugins may refuse uninstall; treat that as expected.
