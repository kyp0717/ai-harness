# Project brief

Gated Project app for task Overview, optional Threads and PRs sections, and Agent/Team/User context-store files with refresh and previews.

## Sub-features

- overview: task overview for the project
- context-files: Agent / Team / User context files
- refresh-preview: refresh and preview context files

## How to get to it (user POV)

Open the Project app from the app panes when the gate is on. Browse context files and previews.

## Driving it with control-atlas

Enable the gate, open Project, snapshot the sections that exist for the fixture project.

Preview a known context file; assert the preview pane.

## Gotchas

- Gated hard. If the app is missing, record the gate and skip.
