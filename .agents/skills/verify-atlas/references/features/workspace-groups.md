# Workspace groups

Local Projects in the left rail: create a persistent local parent, add interactive child threads, switch conversations in tabs or panes.

## Sub-features

- project-parent: persistent local project row
- child-threads: interactive children under a project
- child-tabs-panes: switch children in tabs or split panes

## How to get to it (user POV)

Create a Project from the left rail section. Add a child from the project overflow. Switch children from tabs above the transcript.

## Driving it with control-atlas

Create a disposable project, add two children, send in each, assert isolation (see also `multi-surface-journeys.md`).

## Gotchas

- Deleting a project may archive children; read the confirm copy before accepting.
